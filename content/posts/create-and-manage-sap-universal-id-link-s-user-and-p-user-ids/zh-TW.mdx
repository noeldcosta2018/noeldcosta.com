SAP Universal ID 是一個免費的個人 SAP 帳戶，存放您所有的 S-User 與 P-User ID、證照以及 SAP Community 聲譽，換工作時它也跟著您。自 2026 年起，它不再用來登入：您以各個 S-User 或 P-User ID 登入，而使用者會透過電子郵件地址自動連結到它。

> **簡短回答。** P-User 是您自己的 SAP 使用者。S-User 由雇主或客戶以其 SAP 客戶編號核發。SAP Universal ID 就像一個錢包，在 account.sap.com 的 SAP Account Manager 中列出所有這些使用者。

我剛接觸 SAP 時，花了好幾週才搞懂 P-User、S-User，以及它們之間怎麼連結。重設密碼的郵件幾乎每週都有。

## S-User、P-User 與 Universal ID 的差別

下表列出每種 ID 屬於誰、用來做什麼，以及您離開公司時會發生什麼事。

| | P-User | S-User | SAP Universal ID |
|---|---|---|---|
| 屬於誰 | 您 | 您的雇主或客戶，在其 SAP 客戶編號下 | 您 |
| 由誰建立 | 您，在 account.sap.com 註冊 | 該公司的管理員，在 SAP for Me 中建立 | 您，在 account.sap.com 建立 |
| 用途 | SAP Community、試用、開發者內容、SAP Learning | 支援案件、軟體下載、授權金鑰、系統資料 | 列出您的所有使用者，保留證照與社群聲譽 |
| 能用來登入嗎？ | 可以 | 可以 | 不行，自 2026 年 1 月起 |
| 到期 | 無 | 預設 24 個月，管理員可延長 | 無 |
| 離開公司時 | 沒有變化 | 管理員刪除它，或它到期失效 | 仍屬於您。加入新的工作電子郵件 |

我的 P-User 跟了我大約 16 年，陪我換過好幾份工作。隨著我在不同公司之間轉換，我先後有過六個 S-User。Universal ID 就是把它們全部列在同一份清單上的地方。

## 2026 年有哪些變化

SAP 今年做了兩項變更。官方詳情請見 [SAP 的 Universal ID 頁面](https://www.sap.com/account/universal-id.html)。

<explainer-timeline title="SAP Universal ID 在 2026 年的變化" caption="自 7 月起，新增電子郵件地址就是連結帳戶的方式。手動連結按鈕已經沒有了。" items="2025 年 8 月 => 為每個使用者設定密碼|2026 年 1 月 20 日 => Universal ID 不再用來登入|2026 年 7 月 13 日 => 以電子郵件地址連結帳戶" notes="針對連結了多個身分的使用者，持續到 2026 年 1 月|以 S-User 或 P-User ID 或其電子郵件登入|手動連結取消。7 月之前建立的連結維持不變" highlight="3" source="SAP Universal ID 頁面，sap.com"></explainer-timeline>

1. **2026 年 1 月：Universal ID 不再用來登入。** 它已不再是身分提供者。您以 S-User 或 P-User ID（或該使用者的電子郵件地址）以及該使用者的密碼，透過 SAP Cloud Identity Services（SAP IAS）登入。
2. **2026 年 7 月 13 日：以電子郵件地址連結。** 手動連結與取消連結的選項以及 Linked 狀態欄都已移除。凡是電子郵件已登錄在您 Universal ID 中的 S-User 或 P-User，都會自動連結；7 月之前手動連結的，維持連結不變。

兩次變更都沒有刪除任何帳戶。如果您跳過了 2025 年為每個使用者設定密碼的提示，請在該使用者上使用 Forgot password（忘記密碼）。

## 如何管理您的 SAP Universal ID：逐步說明

這裡有兩個網址很重要，而且容易搞混。**account.sap.com** 是 SAP Account Manager，您的 Universal ID 就在這裡。多一個 s 的 accounts.sap.com 是每個個別使用者的個人資料頁面，密碼與雙因素驗證設定都在那裡。

### 如何建立 SAP Universal ID

1. 前往 [account.sap.com](https://account.sap.com/)，開始新的註冊。表單標題是「Register your SAP ID」。
2. 輸入您的姓名與個人電子郵件地址，不要用工作信箱。
3. 使用者名稱可以留空，也可以自己選：最多 30 個字元，可用拉丁字母、數字、連字號與底線。如果留空，SAP 會用您的姓名加上數字產生一個。
4. 接受 Terms of Use（使用條款），完成驗證碼挑戰，然後點選 **Register**。
5. 輸入 SAP 寄到您信箱的驗證碼。驗證碼 15 分鐘內有效。

註冊會建立您的 Universal ID，以及一個與之連結的使用者身分。如果您已經有 Universal ID，就不要再註冊第二個，而是把新的電子郵件加入現有的那一個。

### 如何將 S-User 連結到 SAP Universal ID

自 2026 年 7 月起，連結 S-User 的方式是新增它的電子郵件地址，而不是新增使用者本身。

1. 在 [account.sap.com](https://account.sap.com/) 登入 SAP Account Manager。
2. 開啟 **Accounts** 分頁，點選 **Add accounts**。
3. 輸入該 S-User 上登錄的電子郵件地址。
4. 輸入 SAP 寄到該地址的驗證碼。
5. 檢查清單。使用該電子郵件的所有 S-User 與 P-User 現在都會出現在您的 Universal ID 下。

如果 S-User 沒有出現，表示它的電子郵件與您新增的不同。請詢問建立該使用者的管理員，使用者上登錄的是哪個地址。

### 如何新增 P-User

舊的 P-User 也用同樣的方式連結。依上面的五個步驟，新增註冊該 P-User 時使用的電子郵件地址。如果您根本沒有 P-User，註冊 Universal ID 的同時就會取得一個使用者身分。

### 如何重設 SAP 密碼

現在已經沒有另外一組、用來登入 SAP 網站的 Universal ID 密碼需要重設了。您要重設的是特定 S-User 或 P-User 的密碼。

1. 前往 [accounts.sap.com](https://accounts.sap.com/)，點選 **Forgot password?**
2. 輸入使用者 ID（SAP 建議）或電子郵件。如果多個使用者共用該電子郵件，就必須輸入使用者 ID。
3. 點選 **Send**。
4. 開啟郵件，點選 **Click here to reset your password**。連結會在 2 小時內失效。
5. 輸入至少 8 個字元的新密碼，需包含小寫字母、大寫字母、數字、符號中的三類。
6. 再輸入一次，然後點選 **Save**。

每 24 小時只能變更或重設一次密碼。如果一直收不到郵件，SAP 的指南建議寫信到 sso@sap.com。

### 如何從 Universal ID 移除使用者

自 2026 年 7 月 13 日起沒有取消連結的按鈕，您也無法自行刪除 S-User。SAP 的做法是請擁有該使用者的公司的管理員處理。

1. 請該公司的管理員刪除這個 S-User。
2. 管理員在 SAP for Me 中開啟 User Management 應用程式，在 Actions 欄點選 Delete。
3. 如果該 S-User 擔任特殊職能，例如軟體接收人或技術聯絡人，SAP 必須先把這個職能移轉給其他人。
4. 刪除後，S-User 會在 Deleted Users 中保留 12 個月，且無法重新啟用。

若要刪除 Universal ID 本身，請聯絡 SAP 的 Customer Interaction Center（CIC）。

### 如何變更 Universal ID 的電子郵件

1. 在 [account.sap.com](https://account.sap.com/) 登入 SAP Account Manager。
2. 在 **Accounts** 分頁點選 **Add accounts**，輸入新地址。
3. 輸入寄到新地址的驗證碼。
4. 開啟 **Personal Info** 分頁，把新地址設為主要地址。

請保留您的個人地址作為備用。S-User 上的電子郵件是另一回事：只有該公司的管理員能變更。它一旦變更，這個 S-User 就會移到持有新地址的那個 Universal ID 下。

### 如何開啟雙因素驗證

SAP 在每個使用者的個人資料中提供以時間為基礎的一次性密碼（TOTP）雙因素驗證。

1. 在 [accounts.sap.com](https://accounts.sap.com/) 登入。
2. 捲動到 **TOTP Two-Factor Authentication**，點選 **Activate**。
3. 安裝一個驗證器應用程式。SAP 建議使用 Microsoft Authenticator 或 Google Authenticator。
4. 用應用程式掃描 QR 碼。
5. 輸入應用程式顯示的驗證碼，點選 **Activate**。

接著頁面會顯示「You have a device configured for TOTP two-factor authentication」，SAP 也會寄出一封郵件。換手機時，要先點選 **Deactivate** 並以驗證碼確認，再於新裝置上重新啟用。您的超級管理員可以強制啟用 MFA，這會覆蓋您自己的選擇。

## SAP Universal ID 常見錯誤與解決方法

2026 年變更之後，多數問題都歸結到電子郵件地址、依使用者設定的密碼與到期日。

| 問題 | 最可能的原因 | 解決方法 |
|---|---|---|
| 某個使用者沒有出現在 Accounts 分頁 | 它的電子郵件與您 Universal ID 中的地址不同 | 在 Accounts 新增該電子郵件，或請管理員更正 S-User 上的電子郵件 |
| 使用者或電子郵件已連結到另一個 Universal ID | 它在您以前建立的舊 Universal ID 下 | 提出 SAP 支援案件或聯絡 CIC。SAP 的 KBA 使用元件 `XX-SER-UID` |
| 以電子郵件登入失敗 | 多個使用者共用該電子郵件 | 改用 S-User 或 P-User ID 登入 |
| 2026 年 1 月後舊密碼被拒絕 | 現在每個使用者都有自己的密碼 | 在該使用者上使用 Forgot password |
| 密碼被鎖定 | 錯誤嘗試次數過多 | 重設密碼。我自己每年至少會遇到一次 |
| 無法再次變更密碼 | 每 24 小時只能變更或重設一次 | 等待 24 小時 |
| 收不到重設郵件 | 垃圾郵件過濾，或用錯了使用者 | 檢查垃圾郵件，用使用者 ID 重試，再寫信到 sso@sap.com |
| 在某個瀏覽器登入失敗 | 第三方 Cookie 被封鎖，或使用 Internet Explorer | 允許第三方 Cookie，並使用最新版的 Chrome、Edge、Firefox 或 Safari |
| S-User 已到期 | 超過到期日 | 管理員可在 90 天內重新啟用。超過後會被刪除，需要新的 S-User |
| 已登入但無法建立案件或下載 | 該 S-User 缺少相應權限 | 在 SAP for Me 申請，由您的管理員核准 |

Universal ID 從不改變權限。每個 S-User 保有由該公司管理員授予的自身權限。

## 如果您持有多個 S-User

1 月的變更對顧問的影響最大。過去一個登入就能涵蓋所有客戶。現在每個 S-User 都有自己的密碼，切換使用者就得登出再重新登入。

把每個 S-User 當作客戶的資產，而不是您自己的。在密碼管理工具中為每個 S-User 建立一筆項目，註明客戶名稱與客戶編號。SAP 的上限很寬鬆：一個 Universal ID 最多可容納 10 個電子郵件地址與 100 個 S-User 或 P-User，但全部都必須屬於您本人。

留意到期日。新 S-User 預設有效 24 個月，之後進入 90 天的即將到期階段，在到期前 30 天、14 天與 2 天會收到郵件。您可以自行在 SAP for Me 申請延長，申請會送到管理員那裡。

### 如何查詢您的 S-User ID

1. 在 account.sap.com 登入 SAP Account Manager，開啟 **Accounts** 分頁。它列出連結到您 Universal ID 的所有使用者。
2. 在 SAP for Me 中，**My authorizations & functions**（我的權限與職能）會顯示您目前登入的使用者能做什麼。
3. 如果從沒收到過 S-User，您可能根本沒有。貴公司的管理員可以在 User Management 應用程式中看到所有 S-User。

### 如何找到貴公司的超級管理員

SAP 會為新客戶建立第一個 S-User，並將它設為超級管理員。之後，貴公司的管理員負責建立其他所有 S-User。SAP 建議至少再設兩位超級管理員作為備援。

1. 用該公司的任一個 S-User 登入 SAP for Me。
2. 開啟 **Users & Contacts**，再開啟 **Important contacts**（重要聯絡人）。這裡列出超級管理員、雲端管理員與資安聯絡人。
3. 如果超級管理員已經離職，且沒有其他人能處理，請在元件 `XX-SER-FORME` 上提出案件，註明應由誰接手。

如果您還沒有 S-User，先去找 IT 部門裡負責提出 SAP 支援案件的人。請注意，管理員看不到某個 S-User 是否已連結到 Universal ID，所以這一端的問題他們無法替您處理。

## 加入與離開客戶專案時的檢查清單

顧問會在專案開始與結束時碰到這些問題。我會依以下順序處理。

1. **第一天之前：** 確認您的 Universal ID 有一個個人主要電子郵件。
2. **第一天：** 請客戶的管理員在其客戶編號下為您建立一個 S-User，使用您在那裡會用的電子郵件。
3. **同一天：** 把該電子郵件加入 SAP Account Manager，並確認新的 S-User 已經出現。
4. **第一週：** 只申請您的角色所需的權限；如果客戶沒有強制要求，就自己開啟雙因素驗證。
5. **專案期間：** 如果您的多個使用者共用同一個地址，請以 S-User ID 而不是電子郵件登入。
6. **離開之前：** 確認您的個人電子郵件在 Universal ID 中。把證照移轉到新的 S-User 需要提出支援案件。
7. **離開之後：** 預期該 S-User 會被刪除。您的 P-User 與 Universal ID 仍會保留。

S-User 綁定一個客戶編號，不能移到另一個編號，所以換新客戶就一定需要新的 S-User。如果客戶也給了您 BTP 存取權限，請從我的 [SAP BTP Cockpit 指南](/zh-TW/master-the-sap-btp-cockpit-simple-steps/)開始。那裡的登入失敗是另一類問題，在我的 [BTP Cockpit 疑難排解指南](/zh-TW/sap-btp-cockpit-issues/)中有說明。

<summary>我可以有多個 S-User 嗎？</summary>

可以。每個公司或客戶編號各有一個，因為 S-User 不能在客戶編號之間移轉。一個 Universal ID 最多可容納 10 個電子郵件地址與 100 個 S-User 或 P-User，前提是它們全部屬於您本人。

</details>

<details>
<summary>如何重設 SAP Universal ID 密碼？</summary>

重設特定 S-User 或 P-User 的密碼。前往 accounts.sap.com，點選 Forgot password?，輸入使用者 ID 並點選 Send，然後在 2 小時內使用郵件中的連結。每 24 小時只能重設一次。

</details>
