Quand j’ai débuté avec SAP, j’ai passé des semaines à essayer de comprendre les P-Users, les S-Users et ce qui était relié à quoi. Se connecter voulait dire vérifier quel mot de passe allait avec quel système. Les e-mails de réinitialisation arrivaient toutes les semaines. Si vous travailliez sur plusieurs clients, multipliez ça par le nombre de paysages systèmes que vous touchiez.

SAP Universal ID règle ce problème. Un seul identifiant qui relie tous vos comptes SAP (personnel, entreprise ou client). La configuration prend environ 10 minutes. Le gain de temps commence dès le lendemain matin.

## Les trois types d’identifiants et ce qu’ils signifient vraiment

| Type d’identifiant | À qui il appartient | Ce qu’il vous donne | Ce qui se passe quand vous partez |
|---|---|---|---|
| **P-User** | Vous, personnellement | SAP Community, essais gratuits, contenu développeur, événements | Rien ne change : il vous appartient |
| **S-User** | Votre employeur | Portail de support sous licence, téléchargements logiciels, enregistrement des systèmes, soumission de tickets | L’entreprise le désactive |
| **Universal ID** | Vous, personnellement | Connexion unique reliant vos P-Users et S-Users | Vous le conservez ; il suffit de dissocier les S-Users de l’entreprise |

Mon P-User me suit depuis plus de 16 ans, à travers différents postes. J’ai eu six S-Users différents en changeant d’entreprise. Universal ID est la seule raison pour laquelle gérer tout cela ne me prend pas un quart de ma matinée.

Point important : utilisez une adresse e-mail personnelle lorsque vous créez votre Universal ID, pas votre e-mail professionnel. Si vous quittez l’entreprise et perdez l’accès à votre messagerie pro, vous pourriez vous retrouver bloqué hors de votre propre compte.

## Configurer Universal ID et relier les comptes

### Étape 1 : créer votre SAP Universal ID

1. Allez sur [account.sap.com](https://account.sap.com)
2. Cliquez sur **Register** (visible sur la page principale)
3. Renseignez vos informations personnelles : nom, e-mail personnel, mot de passe
4. Acceptez les conditions générales (l’opt-in marketing est facultatif)
5. Vérifiez votre boîte de réception pour l’e-mail de vérification : saisissez le code dans les 10 minutes
6. Connectez-vous avec vos nouveaux identifiants : votre Universal ID est maintenant actif
7. Reliez tous les comptes P-User ou S-User existants depuis l’écran affiché après connexion

L’ensemble du processus prend environ 10 minutes. Faites-le quand vous avez tous vos identifiants de compte SAP à portée de main, pour tout relier en une seule fois.

### Étape 2 : relier les comptes S-User et P-User

Si vous avez déjà créé votre Universal ID et souhaitez relier des comptes existants :

1. Connectez-vous sur [account.sap.com](https://account.sap.com)
2. Cliquez sur l’icône de votre profil (en haut à droite) → **Account Settings**
3. Dans la barre latérale gauche, sélectionnez **Linked Accounts**
4. Cliquez sur **Link Account**
5. Saisissez le nom d’utilisateur et le mot de passe du S-User ou du P-User que vous voulez relier
6. Vérifiez que le compte apparaît dans votre liste de comptes liés
7. Répétez l’opération pour tout compte supplémentaire

Une fois les comptes liés, vous accédez à tout via votre Universal ID. Il y a une limite d’environ 10 comptes liés : si vous l’atteignez, dissociez les comptes que vous n’utilisez plus.

## Obtenir un S-User ou un P-User au départ

### Provisionner un S-User

Les S-Users viennent de l’administrateur SAP de votre entreprise, pas directement de SAP. Votre administrateur les provisionne via l’espace User Management dans le SAP Support Portal (désormais intégré à SAP for Me, le portail client unifié 2026). Les autorisations typiques à demander :

1. **Support** : pour soumettre des tickets
2. **License** : pour la gestion des licences
3. **Download** : pour les téléchargements logiciels
4. **Systems** : pour l’enregistrement des systèmes

Si vous ne trouvez pas votre administrateur SAP, commencez par l’IT. Dans les petites entreprises, vérifiez aussi auprès de la Finance : ils ont presque toujours un accès S-User pour des raisons de licence et sauront qui est l’administrateur.

Quand vous partez, l’entreprise désactive votre S-User. C’est normal. C’est son compte, pas le vôtre. Sur les programmes RISE with SAP et GROW with SAP, le même modèle s’applique ; le client provisionne toujours les S-Users pour les consultants engagés dans le tenant du client.

### Enregistrer un P-User

Enregistrez-vous sur [account.sap.com](https://account.sap.com). Le formulaire demande votre nom, votre e-mail et quelques informations professionnelles de base. Vérifiez votre adresse e-mail, et c’est bon. Les P-Users vous donnent accès à SAP Community, aux systèmes d’essai gratuits, aux ressources développeur, aux supports de formation et à l’inscription aux événements. Ils ne donnent pas accès au support sous licence ni aux téléchargements. C’est à cela que servent les S-Users.

## Erreurs de liaison courantes et correctifs

La plupart des erreurs se ramènent à l’une de ces cinq causes racines :

| Erreur | Cause la plus probable | Correctif |
|---|---|---|
| "Already linked to a different Universal ID" | Le S-User ou le P-User a déjà été lié ailleurs | Contactez le support SAP pour supprimer l’ancienne association, ou ouvrez un ticket `XX-SER-SAPSMP-USR` |
| "Email address mismatch" | L’e-mail du S-User/P-User ne correspond pas à l’e-mail de votre Universal ID | Mettez à jour l’e-mail de l’ancien compte via votre administrateur SAP ou le portail en libre-service |
| "Not authorized to link this user ID" | Vous n’avez pas l’autorisation de gérer ce compte (mauvaise entreprise ou rôle insuffisant) | Vérifiez avec votre administrateur SAP que le S-User est bien affecté à votre entreprise et que vous êtes le bon utilisateur |
| "This S-user is inactive or has been deleted" | Compte désactivé, généralement après avoir quitté un ancien employeur | Demandez une réactivation à l’administrateur SAP de l’entreprise, ou laissez tomber s’il venait d’un ancien poste |
| "Account temporarily locked" | Trop de tentatives de connexion ou de liaison échouées | Attendez 30 minutes, puis réessayez. Ça m’arrive au moins une fois par an quand je repasse en revue d’anciens identifiants. |
| "Too many linked accounts" | Vous avez atteint la limite d’environ 10 comptes | Allez dans Linked Accounts, supprimez les comptes que vous n’utilisez plus, puis réessayez |

Pour tout ce qui ne se résout pas en libre-service, ouvrez un ticket de support sous le composant `XX-SER-SAPSMP-USR`.

## Gérer vos comptes liés au quotidien

Le basculement entre comptes liés se fait depuis l’écran Linked Accounts après connexion : pas besoin de se déconnecter puis de se reconnecter. Certains services SAP n’acceptent que des types de comptes précis : les tickets de support et les téléchargements logiciels nécessitent un S-User avec les bonnes autorisations ; les publications sur SAP Community utilisent l’identité de votre P-User. Utiliser le mauvais type provoque des erreurs d’accès qui peuvent sembler confuses tant que vous n’avez pas compris la différence.

Si vous avez besoin d’autorisations S-User supplémentaires (comme la gestion des licences ou l’enregistrement des systèmes), demandez-les à l’administrateur SAP de votre entreprise. C’est lui qui contrôle ce que chaque S-User peut faire via l’espace User Management : ce ne sont pas des permissions que vous pouvez modifier depuis votre côté Universal ID.

Pour dissocier un compte :
1. Allez sur [accounts.sap.com](https://accounts.sap.com)
2. Connectez-vous avec votre Universal ID
3. Cliquez sur **Account Settings** → **Linked Accounts**
4. Trouvez le compte et cliquez sur **Unlink / Remove**
5. Confirmez

Universal ID simplifie la connexion. Il ne change pas les autorisations, chaque compte conserve ses droits d’accès spécifiques, quelle que soit la façon dont il est lié.

## Questions fréquentes

<details>
<summary>Quelle est la différence entre un P-User et un S-User dans SAP ?</summary>

Un P-User est personnel : vous l’enregistrez vous-même, il vous appartient et il vous suit quand vous changez de poste. Il vous donne accès à SAP Community, aux essais gratuits, au contenu développeur et aux ressources de formation.

Un S-User appartient à votre employeur. Il est provisionné par l’administrateur SAP de votre entreprise et donne accès aux services sous licence (tickets de support, téléchargements logiciels, enregistrement des systèmes). Quand vous quittez l’entreprise, elle le désactive.

SAP Universal ID relie les deux types sous une seule connexion, pour que vous n’ayez pas à les gérer comme des identifiants séparés.

</details>

<details>
<summary>Est-ce que SAP Universal ID change ce à quoi j’ai accès dans les systèmes SAP ?</summary>

Non. Universal ID facilite la connexion : il ne change pas les autorisations, chaque compte lié conserve son propre jeu de permissions. Si votre S-User n’a pas les droits de téléchargement, le fait de le lier à un Universal ID ne les ajoute pas. Les droits d’accès restent contrôlés par l’administrateur SAP de votre entreprise.

</details>

<details>
<summary>Quelle adresse e-mail dois-je utiliser lors de la création de mon SAP Universal ID ?</summary>

Utilisez une adresse e-mail personnelle, pas votre e-mail professionnel. Si vous quittez l’entreprise et perdez l’accès à l’adresse professionnelle avant d’avoir mis à jour les paramètres de votre Universal ID, vous pouvez vous retrouver bloqué. Une adresse e-mail personnelle permet à votre Universal ID de rester accessible независимоamment des changements d’emploi.

</details>

<details>
<summary>Que devient mon SAP Universal ID quand je change de poste ?</summary>

Votre Universal ID reste avec vous : c’est votre compte personnel. Ce qui change, c’est l’accès au S-User de votre ancienne entreprise. Une fois parti, l’entreprise désactive généralement ce S-User. Vous le dissociez de votre Universal ID et vous liez le S-User de votre nouvel employeur lorsqu’il est provisionné.

Votre P-User et votre Universal ID restent inchangés tout au long du processus.

</details>

<details>
<summary>Combien de comptes puis-je lier à SAP Universal ID ?</summary>

Il existe une limite pratique d’environ 10 comptes liés. Si vous l’atteignez, allez dans Linked Accounts dans Account Settings et supprimez les comptes que vous n’utilisez plus avant d’en lier de nouveaux.

Les consultants qui travaillent sur plusieurs clients finiront par atteindre cette limite. La solution de contournement consiste à ne garder liés que les S-Users des clients actifs et à supprimer les anciens une fois les missions terminées.

</details>

<details>
<summary>Que dois-je faire si je n’arrive pas à me connecter à mon SAP Universal ID ?</summary>

Commencez par essayer la réinitialisation standard du mot de passe depuis account.sap.com. Si vous êtes bloqué après trop de tentatives échouées, attendez 30 minutes puis réessayez.

Si vous avez perdu l’accès à l’adresse e-mail associée à votre Universal ID (par exemple, une adresse professionnelle qui a été désactivée), ouvrez un ticket de support sous le composant `XX-SER-SAPSMP-USR`. Le support SAP peut vous aider à récupérer l’accès, mais le processus implique une vérification d’identité, donc cela prend quelques jours.

</details>
