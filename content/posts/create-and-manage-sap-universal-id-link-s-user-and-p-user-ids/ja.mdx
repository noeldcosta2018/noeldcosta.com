SAP Universal IDは、すべてのS-UserとP-UserのID、認定資格、SAP Communityでの評価を保持する無料の個人用SAPアカウントで、転職してもあなたと一緒に残ります。2026年以降、これはログインに使うものではなくなりました。各S-UserまたはP-UserのIDでサインインし、ユーザーはメールアドレスによって自動的にUniversal IDに紐付きます。

> **結論から言うと：** P-Userはあなた自身のSAPユーザーです。S-Userは、雇用主または顧客が自社のSAPカスタマー番号の下で発行するものです。SAP Universal IDは、それらすべてをaccount.sap.comのSAP Account Managerに一覧表示する「財布」です。

SAPを始めたばかりの頃、私はP-User、S-User、そして何が何につながっているのかを理解しようとして何週間も費やしました。パスワードリセットのメールは毎週のように届いていました。

## S-User、P-User、Universal IDの違い

下の表は、各IDの所有者、用途、会社を離れたときに何が起きるかをまとめたものです。

| | P-User | S-User | SAP Universal ID |
|---|---|---|---|
| 所有者 | あなた | 雇用主または顧客（そのSAPカスタマー番号の下） | あなた |
| 作成者 | あなた（account.sap.comで登録） | その会社の管理者（SAP for Meで作成） | あなた（account.sap.comで作成） |
| 用途 | SAP Community、トライアル、開発者向けコンテンツ、SAP Learning | サポートケース、ソフトウェアのダウンロード、ライセンスキー、システムデータ | すべてのユーザーの一覧化、認定資格とコミュニティでの評価の保持 |
| ログインに使えるか | はい | はい | いいえ（2026年1月以降） |
| 有効期限 | なし | 既定で24か月、管理者が延長可能 | なし |
| 会社を離れたとき | 何も変わらない | 管理者が削除するか、期限切れになる | そのまま残る。新しい勤務先のメールアドレスを追加 |

私のP-Userは、約16年にわたり転職を重ねる間もずっと私と一緒でした。会社を移るたびに、S-Userは6つ変わりました。Universal IDは、それらすべてが1つのリストに並ぶ場所です。

## 2026年に何が変わったか

SAPは今年、2つの変更を行いました。公式の詳細は[SAPのUniversal IDページ](https://www.sap.com/account/universal-id.html)にあります。

<explainer-timeline title="2026年にSAP Universal IDはどう変わったか" caption="7月以降、アカウントの紐付けはメールアドレスの追加で行います。手動の紐付けボタンはもうありません。" items="2025年8月 => ユーザーごとにパスワードを設定|2026年1月20日 => Universal IDがログインではなくなる|2026年7月13日 => メールアドレスでアカウントを紐付け" notes="複数のIDを紐付けているユーザーに、2026年1月まで求められた|S-UserまたはP-UserのID、またはそのメールアドレスでサインイン|手動の紐付けは廃止。7月より前に作った紐付けはそのまま" highlight="3" source="SAP Universal IDページ、sap.com"></explainer-timeline>

1. **2026年1月：Universal IDはログインではなくなりました。** もはやIDプロバイダーではありません。S-UserまたはP-UserのID（またはそのユーザーのメールアドレス）と、そのユーザーのパスワードで、SAP Cloud Identity Services（SAP IAS）を通じてサインインします。
2. **2026年7月13日：メールアドレスによる紐付け。** 手動のlink/unlinkオプションと、Linkedステータスの列が削除されました。Universal IDに登録されたメールアドレスを持つすべてのS-UserとP-Userが自動的に紐付き、7月より前に手動で紐付けたものは紐付いたまま残ります。

どちらの変更でもアカウントは削除されていません。2025年にユーザーごとのパスワード設定を求められた際にスキップした場合は、そのユーザーで Forgot password（パスワードを忘れた場合）を使ってください。

## SAP Universal IDの管理手順

ここでは2つのアドレスが重要で、混同しやすいので注意してください。**account.sap.com** はSAP Account Managerで、Universal IDはここにあります。sの付くaccounts.sap.comは個々のユーザーのプロフィールページで、パスワードと2要素認証の設定はここにあります。

### SAP Universal IDを作成する方法

1. [account.sap.com](https://account.sap.com/)にアクセスし、新規登録を開始します。フォームのタイトルは「Register your SAP ID」です。
2. 氏名と、勤務先ではなく個人のメールアドレスを入力します。
3. ユーザー名は空欄のままにするか、自分で決めます。最大30文字で、ラテン文字、数字、ハイフン、アンダースコアが使えます。空欄にすると、SAPが氏名と数字から作成します。
4. Terms of Use（利用規約）に同意し、captchaを完了して **Register** をクリックします。
5. SAPからメールで届く確認コードを入力します。有効期間は15分です。

この登録で、Universal IDと、それに紐付いたユーザーIDが作成されます。すでにUniversal IDを持っている場合は、2つ目を登録しないでください。新しいメールアドレスを既存のものに追加します。

### S-UserをSAP Universal IDに紐付ける方法

2026年7月以降、S-Userはユーザーそのものではなく、そのメールアドレスを追加することで紐付けます。

1. [account.sap.com](https://account.sap.com/)でSAP Account Managerにサインインします。
2. **Accounts** タブを開き、**Add accounts** をクリックします。
3. S-Userに登録されているメールアドレスを入力します。
4. SAPがそのアドレスに送るパスコードを入力します。
5. 一覧を確認します。そのメールアドレスを持つすべてのS-UserとP-Userが、Universal IDの下に表示されます。

S-Userが表示されない場合は、そのメールアドレスが追加したものと異なっています。S-Userを作成した管理者に、どのアドレスが登録されているか確認してください。

### P-Userを追加する方法

古いP-Userも同じ方法で紐付きます。上の5つの手順で、そのP-Userを登録したときのメールアドレスを追加してください。P-Userをまったく持っていない場合は、Universal IDを登録すると、同じ手順でユーザーIDも作成されます。

### SAPのパスワードをリセットする方法

SAPのサイトにサインインするための、Universal ID専用のパスワードをリセットする必要はもうありません。リセットするのは、特定のS-UserまたはP-Userのパスワードです。

1. [accounts.sap.com](https://accounts.sap.com/)にアクセスし、**Forgot password?** をクリックします。
2. ユーザーID（SAPの推奨）またはメールアドレスを入力します。複数のユーザーがそのメールアドレスを共有している場合は、ユーザーIDを入力する必要があります。
3. **Send** をクリックします。
4. メールを開き、**Click here to reset your password** をクリックします。リンクは2時間以内に失効します。
5. 8文字以上で、小文字、大文字、数字、記号のうち3種類を使った新しいパスワードを入力します。
6. もう一度入力し、**Save** をクリックします。

パスワードの変更またはリセットは、24時間に1回までです。メールが届かない場合は、sso@sap.com に連絡するようSAPのガイドに書かれています。

### Universal IDからユーザーを削除する方法

2026年7月13日以降、紐付け解除のボタンはなく、S-Userを自分で削除することもできません。SAPの答えは、そのS-Userを所有する会社の管理者に依頼することです。

1. その会社の管理者に、S-Userの削除を依頼します。
2. 管理者はSAP for MeでUser Managementアプリを開き、Actions列のDeleteをクリックします。
3. S-Userがソフトウェア受領者や技術担当窓口などの特別な機能を持っている場合は、先にSAPがその機能を別の人に移す必要があります。
4. 削除されたS-UserはDeleted Usersに12か月間残り、再有効化はできません。

Universal ID自体を削除するには、SAPのCustomer Interaction Center（CIC）に連絡してください。

### Universal IDのメールアドレスを変更する方法

1. [account.sap.com](https://account.sap.com/)でSAP Account Managerにサインインします。
2. **Accounts** タブで **Add accounts** をクリックし、新しいアドレスを入力します。
3. 新しいアドレスに送られたパスコードを入力します。
4. **Personal Info** タブを開き、新しいアドレスをプライマリーに設定します。

個人のメールアドレスは予備として登録したままにしておいてください。S-Userのメールアドレスはそれとは別物で、変更できるのはその会社の管理者だけです。それが変更されると、S-Userは新しいアドレスを持つUniversal IDに移ります。

### 2要素認証を有効にする方法

SAPは、各ユーザーのプロフィールで、時間ベースのワンタイムパスワード（TOTP）による2要素認証を提供しています。

1. [accounts.sap.com](https://accounts.sap.com/)でサインインします。
2. **TOTP Two-Factor Authentication** までスクロールし、**Activate** をクリックします。
3. 認証アプリをインストールします。SAPはMicrosoft AuthenticatorまたはGoogle Authenticatorを推奨しています。
4. アプリでQRコードをスキャンします。
5. アプリに表示されたパスコードを入力し、**Activate** をクリックします。

その後、ページに「You have a device configured for TOTP two-factor authentication」と表示され、SAPからメールが届きます。スマートフォンを替えるときは、先に **Deactivate** をクリックしてコードで確認し、新しい端末で再度有効化します。スーパー管理者がMFAを強制することもでき、その場合はあなた自身の選択より優先されます。

## SAP Universal IDのよくあるエラーと対処法

2026年の変更後に起きる問題のほとんどは、メールアドレス、ユーザーごとのパスワード、有効期限に行き着きます。

| 問題 | 最も可能性の高い原因 | 対処法 |
|---|---|---|
| ユーザーがAccountsタブに表示されない | そのメールアドレスがUniversal IDに登録したアドレスと異なる | Accountsでそのメールアドレスを追加するか、S-Userのメールアドレスの修正を管理者に依頼する |
| ユーザーまたはメールアドレスが別のUniversal IDに関連付けられている | 以前に作成した古いUniversal IDの下にある | SAPのサポートチケットを起票するか、CICに連絡する。SAPのKBAではコンポーネント `XX-SER-UID` を使用 |
| メールアドレスでのサインインに失敗する | 複数のユーザーがそのメールアドレスを共有している | 代わりにS-UserまたはP-UserのIDでサインインする |
| 2026年1月以降、古いパスワードが拒否される | 各ユーザーが独自のパスワードを持つようになった | そのユーザーでForgot passwordを使う |
| パスワードがロックされた | 誤った入力の回数が多すぎる | パスワードをリセットする。私も少なくとも年に1回は経験します |
| パスワードを再度変更できない | 変更またはリセットは24時間に1回まで | 24時間待つ |
| リセットのメールが届かない | 迷惑メールフィルター、またはユーザーの取り違え | 迷惑メールを確認し、ユーザーIDで再試行し、それでも駄目なら sso@sap.com に連絡する |
| 特定のブラウザーでサインインに失敗する | サードパーティCookieのブロック、またはInternet Explorer | サードパーティCookieを許可し、最新のChrome、Edge、Firefox、Safariを使う |
| S-Userの有効期限が切れた | 有効期限を過ぎた | 管理者が90日以内なら再有効化できる。それを過ぎると削除され、新しいS-Userが必要になる |
| サインインはできるが、ケース作成やダウンロードができない | S-Userにその権限がない | SAP for Meで申請する。承認するのは管理者 |

Universal IDが権限を変えることはありません。各S-Userは、その会社の管理者から付与された独自の権限を保持します。

## 複数のS-Userを持っている場合

1月の変更を最も強く感じているのはコンサルタントです。以前は1つのログインですべての顧客をカバーできました。今は各S-Userが独自のパスワードを持ち、ユーザーを切り替えるにはログアウトしてサインインし直す必要があります。

各S-Userは、あなたのものではなく顧客の資産として扱ってください。パスワードマネージャーにはS-Userごとにエントリーを作り、顧客名とカスタマー番号を記録しておきます。SAPの上限には余裕があり、1つのUniversal IDで最大10個のメールアドレスと、最大100個のS-UserまたはP-Userを保持できます。ただし、すべてあなた本人のものである必要があります。

有効期限に注意してください。新しいS-Userの有効期間は既定で24か月で、その後90日間の失効フェーズに入り、失効の30日前、14日前、2日前にメールが届きます。延長はSAP for Meから自分で申請でき、申請は管理者に届きます。

### 自分のS-User IDを確認する方法

1. account.sap.comでSAP Account Managerにサインインし、**Accounts** タブを開きます。Universal IDに紐付いたすべてのユーザーが一覧表示されます。
2. SAP for Meでは、**My authorizations & functions**（自分の権限と機能）で、サインイン中のユーザーにできることを確認できます。
3. 一度もIDを受け取っていないなら、S-Userを持っていない可能性があります。会社の管理者は、User ManagementアプリですべてのS-Userを確認できます。

### 自社のスーパー管理者を確認する方法

SAPは新しい顧客に最初のS-Userを作成し、それをスーパー管理者にします。その後は、社内の管理者が他のすべてのS-Userを作成します。SAPは、バックアップとして少なくともさらに2人のスーパー管理者を置くことを推奨しています。

1. その会社の任意のS-UserでSAP for Meにサインインします。
2. **Users & Contacts** を開き、**Important contacts**（重要な連絡先）を開きます。スーパー管理者、クラウド管理者、セキュリティ担当窓口が一覧表示されます。
3. スーパー管理者が退職していて他に対応できる人がいない場合は、コンポーネント `XX-SER-FORME` でケースを起票し、引き継ぐべき人を指名してください。

まだS-Userを持っていない場合は、IT部門でSAPのサポートケースを起票している人に相談するところから始めてください。管理者からは、S-UserがUniversal IDに紐付いているかどうかは見えないため、その部分を管理者に直してもらうことはできない点に注意してください。

## 顧客先への参画時と離任時のチェックリスト

コンサルタントがこうした問題にぶつかるのは、プロジェクトの開始時と終了時です。私なら次の順序で進めます。

1. **初日の前：** Universal IDのプライマリーメールアドレスが個人のものであることを確認します。
2. **初日：** 顧客の管理者に、顧客のカスタマー番号の下で、そこで使うメールアドレスを登録したS-Userを依頼します。
3. **同じ日：** そのメールアドレスをSAP Account Managerに追加し、新しいS-Userが表示されることを確認します。
4. **最初の1週間：** 自分の役割に必要な権限だけを申請し、顧客が強制していなければ2要素認証を有効にします。
5. **プロジェクト期間中：** 複数のユーザーが同じアドレスを共有している場合は、メールアドレスではなくS-User IDでサインインします。
6. **離任の前：** 個人のメールアドレスがUniversal IDに登録されていることを確認します。認定資格を新しいS-Userに移すにはサポートチケットが必要です。
7. **離任後：** S-Userは削除されるものと考えてください。P-UserとUniversal IDは残ります。

S-Userは1つのカスタマー番号に結び付いていて別の番号には移せないため、新しい顧客では必ず新しいS-Userが必要になります。顧客からBTPへのアクセスも付与されたら、私の[SAP BTPコックピットガイド](/ja/master-the-sap-btp-cockpit-simple-steps/)から始めてください。そちらでのログイン失敗は別の問題で、私の[BTPコックピットのトラブルシューティングガイド](/ja/sap-btp-cockpit-issues/)で扱っています。

<details>
<summary>SAP Universal IDのログインは今どのように機能しますか？</summary>

2026年1月以降、Universal IDではログインしません。S-UserまたはP-UserのID（またはそのユーザーのメールアドレス）と、そのユーザー自身のパスワードでサインインします。複数のユーザーが1つのメールアドレスを共有している場合は、ユーザーIDを使ってください。

</details>

<details>
<summary>自分のS-User IDはどうやって確認できますか？</summary>

account.sap.comでSAP Account Managerにサインインし、Accountsタブを開きます。Universal IDに紐付いたすべてのユーザーが一覧表示されます。そこにない場合は、会社のSAP管理者に確認してください。管理者はSAP for MeのUser Managementアプリで、社内のすべてのS-Userを確認できます。

</details>

<details>
<summary>S-Userを複数持つことはできますか？</summary>

はい。S-Userはカスタマー番号の間を移動できないため、会社またはカスタマー番号ごとに1つずつ持つことになります。1つのUniversal IDで、最大10個のメールアドレスと最大100個のS-UserまたはP-Userを保持できます。ただし、すべてあなた本人のものである必要があります。

</details>

<details>
<summary>SAP Universal IDのパスワードをリセットするにはどうすればよいですか？</summary>

特定のS-UserまたはP-Userのパスワードをリセットします。accounts.sap.comにアクセスし、Forgot password?をクリックし、ユーザーIDを入力してSendをクリックしたら、2時間以内にメールのリンクを使います。リセットは24時間に1回までです。

</details>
