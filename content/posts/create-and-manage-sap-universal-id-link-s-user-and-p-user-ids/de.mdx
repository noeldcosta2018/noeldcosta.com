Wenn Sie mehr als ein SAP-Konto haben (einen persönlichen P-User plus S-User von Arbeitgebern oder Kunden), ist die SAP Universal ID das persönliche Konto, das alle zusammenhält. 2026 hat sie sich zweimal geändert. Seit dem 20. Januar ist sie kein Login mehr: Sie melden sich mit der S-User- oder P-User-ID an, oder mit der E-Mail-Adresse dieses Users, und mit dem eigenen Passwort dieses Users. Seit dem 13. Juli gibt es keine manuelle Verknüpfung mehr. Sie hinterlegen E-Mail-Adressen im SAP Account Manager, und jeder User mit passender Adresse wird automatisch zugeordnet. Falls Sie noch keine eingerichtet haben, registrieren Sie sich auf account.sap.com mit einer privaten E-Mail-Adresse und fügen dann Ihre geschäftlichen Adressen hinzu.

Als ich neu bei SAP war, habe ich mehrere Wochen gebraucht, um zu verstehen, wie Universal IDs, S-User und P-User zusammenspielen. Vor der Universal ID war der Überblick über all diese Konten ein Albtraum: Passwort-Tabellen und ständige Reset-Mails, wenn man vergessen hatte, welche Zugangsdaten wohin gehören.

## S-User, P-User und Universal ID im Vergleich

Die Tabelle zeigt, wem welche ID gehört und wofür sie gedacht ist.

| ID-Typ | Wem sie gehört | Wofür Sie sie nutzen | Wenn Sie gehen |
|---|---|---|---|
| **P-User** | Ihnen | SAP Community, Testversionen, Entwicklerinhalte, SAP Learning | Es ändert sich nichts. Er gehört Ihnen |
| **S-User** | Ihrem Arbeitgeber oder Kunden, unter dessen SAP-Kundennummer | Support-Fälle, Software-Downloads, Lizenzschlüssel, Systemdaten in SAP for Me | Der Administrator löscht ihn, oder er erreicht sein Ablaufdatum |
| **Universal ID** | Ihnen | Hält Ihre S-User und P-User in einer Liste, dazu Lernzertifikate und Ihre Reputation in der SAP Community | Sie behalten sie. Fügen Sie die E-Mail-Adresse Ihres neuen Arbeitgebers hinzu |

Mein P-User begleitet mich seit rund 16 Jahren durch verschiedene Jobs. Beim Wechsel zwischen Unternehmen hatte ich sechs verschiedene S-User. In der Universal ID stehen sie alle in einer Liste.

Nutzen Sie für Ihre Universal ID eine private E-Mail-Adresse, nicht die geschäftliche. Die FAQ von SAP selbst empfiehlt dasselbe. Wenn Sie das Unternehmen verlassen und das Firmenpostfach verlieren, ist die private Adresse Ihr Weg zurück ins Konto.

## Was sich 2026 geändert hat

SAP hat in diesem Jahr zwei Änderungen vorgenommen. Beide betreffen die Anmeldung und die Verknüpfung der Konten. Die offiziellen Details stehen auf der [Universal-ID-Seite von SAP](https://www.sap.com/account/universal-id.html).

1. **20. Januar 2026: Universal-ID-Login abgeschaltet.** Die Universal ID ist kein Identity Provider mehr. Sie melden sich mit der S-User- oder P-User-ID an, oder mit der E-Mail-Adresse dieses Users, plus dem Passwort dieses Users. Die Authentifizierung läuft über SAP Cloud Identity Services. Wer mehrere verknüpfte Identitäten hatte, sollte zwischen August 2025 und Januar 2026 für jede ein Passwort festlegen. Haben Sie das übersprungen, nutzen Sie bei jedem User „Passwort vergessen“.
2. **13. Juli 2026: Verknüpfung per E-Mail-Adresse.** Die Optionen zum manuellen Verknüpfen und Trennen sind entfallen. Jeder S-User oder P-User, dessen E-Mail-Adresse in Ihrer Universal ID registriert ist, wird ihr automatisch zugeordnet. Konten, die Sie vor Juli von Hand verknüpft haben, bleiben verknüpft.

Für Berater, die mehrere Kunden-S-User führen, ist die Änderung vom Januar ein Rückschritt. Früher genügte ein Login für alles. Jetzt hat jeder S-User wieder sein eigenes Passwort, und für den Wechsel zwischen Usern müssen Sie sich ab- und wieder anmelden. Notieren Sie in Ihrem Passwort-Manager, welcher S-User zu welchem Kunden und welcher Kundennummer gehört.

## Universal ID einrichten und Konten hinzufügen

### Schritt 1: SAP Universal ID erstellen

1. Rufen Sie [account.sap.com](https://account.sap.com/) auf und klicken Sie auf **Register**.
2. Geben Sie Ihren Namen und eine private E-Mail-Adresse ein und legen Sie ein Passwort fest.
3. Akzeptieren Sie die Nutzungsbedingungen. Die Marketing-Einwilligung ist freiwillig.
4. Geben Sie den Bestätigungscode aus Ihrem Posteingang ein. Er bleibt 15 Minuten gültig.
5. Melden Sie sich im SAP Account Manager an. Ihr neuer P-User steht auf der Registerkarte **Accounts**.

Das Ganze dauert ein paar Minuten. Halten Sie die E-Mail-Adressen Ihrer übrigen SAP-User bereit, damit Sie sie gleich danach hinzufügen können.

### Schritt 2: E-Mail-Adressen Ihrer anderen Konten hinzufügen

1. Melden Sie sich im SAP Account Manager unter [account.sap.com](https://account.sap.com/) an.
2. Öffnen Sie die Registerkarte **Accounts** und klicken Sie auf **Add accounts**.
3. Geben Sie die E-Mail-Adresse ein, die der S-User oder P-User nutzt, den Sie einbinden möchten.
4. Geben Sie den Zugangscode ein, den SAP an diese Adresse schickt.
5. Prüfen Sie die Liste. Jeder User mit dieser E-Mail-Adresse erscheint jetzt unter Ihrer Universal ID.
6. Wiederholen Sie das für jede Adresse und legen Sie dann auf der Registerkarte **Personal Info** Ihre primäre E-Mail-Adresse fest.

Eine Universal ID umfasst bis zu 10 E-Mail-Adressen und bis zu 100 S-User oder P-User. Jeder User kann nur unter einer Universal ID stehen, und alle müssen derselben Person gehören. Der SAP-Knowledge-Base-Artikel 2882908 beschreibt, wie Sie eine zusätzliche E-Mail-Adresse oder einen zusätzlichen User hinzufügen.

### Die tägliche Anmeldung

SAP empfiehlt, sich mit der User-ID (S oder P, gefolgt von Ziffern) anzumelden, wenn sich mehrere Ihrer User eine E-Mail-Adresse teilen. Haben diese User auch dasselbe Passwort, liefert die Anmeldung per E-Mail einen Fehler, weil mehr als ein User passt.

Um den User zu wechseln, melden Sie sich ab und mit dem anderen wieder an. SAP kündigt den Wechsel innerhalb einer Sitzung für später an. Sortieren Sie in der Kontoauswahl nach Anmeldedatum, dann steht Ihr zuletzt genutzter User oben.

## S-User oder P-User bekommen

### Einen S-User bereitstellen lassen

S-User kommen vom Benutzeradministrator Ihres Unternehmens, nicht von SAP. SAP legt nur den ersten Super-Administrator für einen neuen Kunden an. Danach beantragt der Administrator S-User in der [User-Management-App in SAP for Me](https://support.sap.com/content/s4m/help/users/admin.html). Der neue User erhält einen Aktivierungslink, der 10 Tage gültig ist. Bitten Sie den Administrator um die Berechtigungen, die Ihre Rolle braucht:

1. **Support-Fälle**: Incidents anlegen und verfolgen
2. **Software-Download**: Installationen, Patches und Add-ons
3. **Lizenzschlüssel**: Schlüssel für Systeme anfordern
4. **Systemdaten**: Installationen und Systeme pflegen

Ein S-User ist an eine Kundennummer gebunden und lässt sich nicht auf eine andere übertragen. S-User haben außerdem ein Ablaufdatum. Kurz vor dem Ende können Sie in SAP for Me eine Verlängerung beantragen, die Anfrage landet in der Warteschlange Ihres Administrators.

Wenn Sie Ihren SAP-Administrator nicht finden, fragen Sie zuerst die IT. In kleineren Unternehmen fragen Sie im Finanzbereich nach. Dort gibt es fast immer einen S-User-Zugang aus Lizenzgründen, und man weiß, wer der Administrator ist.

Bei RISE with SAP und GROW with SAP gilt dasselbe Modell. Der Kunde legt S-User für seine Berater unter seiner eigenen Kundennummer an und löscht sie, wenn das Projekt endet. Das ist so vorgesehen. Es ist sein Konto, nicht Ihres.

### Einen P-User registrieren

Registrieren Sie sich auf [account.sap.com](https://account.sap.com/) mit Ihrer eigenen E-Mail-Adresse. Damit erhalten Sie in einem Schritt einen P-User und eine Universal ID. P-User decken die SAP Community ab, kostenlose Testversionen wie die in meiner [Anleitung zum SAP BTP Cockpit](/de/master-the-sap-btp-cockpit-simple-steps/), Entwicklerressourcen und SAP Learning. Sie geben keinen Zugriff auf lizenzierten Support oder Software-Downloads. Dafür sind S-User da.

## Häufige Zugriffsfehler und ihre Lösung

Die meisten Probleme nach den Änderungen von 2026 haben mit E-Mail-Adressen und Passwörtern zu tun.

| Problem | Wahrscheinlichste Ursache | Lösung |
|---|---|---|
| Ein User fehlt auf Ihrer Registerkarte Accounts | Seine E-Mail-Adresse weicht von den Adressen in Ihrer Universal ID ab | Fügen Sie diese E-Mail-Adresse unter Accounts hinzu, oder bitten Sie Ihren Administrator, die Adresse am S-User zu korrigieren |
| User bereits einer anderen Universal ID zugeordnet | Er hängt an einer älteren Universal ID, die Sie angelegt haben | Eröffnen Sie einen Fall beim SAP Support (die KBAs von SAP nennen die Komponente `XX-SER-UID`), damit er freigegeben wird |
| Anmeldung per E-Mail schlägt fehl | Mehrere User teilen sich diese E-Mail-Adresse und das Passwort | Melden Sie sich stattdessen mit der S-User- oder P-User-ID an |
| Altes Passwort nach Januar 2026 abgelehnt | Jeder User hat jetzt sein eigenes Passwort | Nutzen Sie „Passwort vergessen“ für genau diesen User |
| Passwort gesperrt | Zu viele Fehlversuche | Warten Sie oder setzen Sie das Passwort zurück. Mir passiert das mindestens einmal im Jahr |
| S-User inaktiv oder abgelaufen | Der Administrator hat ihn gelöscht, oder er hat sein Ablaufdatum überschritten | Bitten Sie den Administrator des jeweiligen Unternehmens, ihn zu verlängern oder zu ersetzen. Stammt er aus einem früheren Job, lassen Sie ihn los |
| Angemeldet, aber keine Fälle anlegbar und kein Download möglich | Dem S-User fehlt diese Berechtigung | Beantragen Sie sie in SAP for Me. Ihr Administrator genehmigt sie |

Wenn Sie sich gar nicht anmelden können, nennt SAP das Customer Interaction Center (CIC) als Ansprechpartner für Hilfe zur Universal ID. Die Wiederherstellung umfasst Identitätsprüfungen. Fangen Sie also früh an, wenn Sie den Zugang für einen Termin brauchen.

## Checkliste für den Einstieg und Ausstieg bei einem Kunden

Berater stoßen zu Beginn und am Ende von Projekten auf diese Probleme. In dieser Reihenfolge würde ich vorgehen.

1. **Vor dem ersten Tag:** Prüfen Sie, ob Ihre Universal ID eine private primäre E-Mail-Adresse hat.
2. **Am ersten Tag:** Bitten Sie den Administrator des Kunden um einen S-User unter dessen Kundennummer, angelegt mit der E-Mail-Adresse, die Sie dort nutzen werden.
3. **Am selben Tag:** Fügen Sie diese E-Mail-Adresse im SAP Account Manager hinzu und prüfen Sie, ob der neue S-User erscheint.
4. **In der ersten Woche:** Beantragen Sie nur die Berechtigungen, die Ihre Rolle braucht. Der Administrator genehmigt sie in SAP for Me.
5. **Während des Projekts:** Melden Sie sich mit der S-User-ID statt mit der E-Mail-Adresse an, wenn sich mehrere Ihrer User eine Adresse teilen.
6. **Bevor Sie gehen:** Haben Sie unter diesem S-User Zertifikate erworben, stellen Sie sicher, dass Ihre private E-Mail-Adresse in Ihrer Universal ID steht. Zertifikate auf einen neuen S-User zu übertragen, erfordert einen Support-Fall.
7. **Nach dem Weggang:** Rechnen Sie damit, dass der S-User gelöscht wird. Ihr P-User und Ihre Universal ID bleiben bestehen.

Wenn der Kunde Ihnen auch BTP-Zugang gibt, sind Anmeldefehler dort ein anderes Problem. Mein [Leitfaden zur Fehlersuche im BTP Cockpit](/de/sap-btp-cockpit-issues/) behandelt die 401-Fehler.

## Häufig gestellte Fragen

<details>
<summary>Was ist der Unterschied zwischen einem P-User und einem S-User in SAP?</summary>

Ein P-User ist persönlich. Sie registrieren ihn selbst, er gehört Ihnen und begleitet Sie durch Jobwechsel. Er gibt Ihnen Zugriff auf die SAP Community, kostenlose Testversionen, Entwicklerinhalte und SAP Learning.

Ein S-User gehört Ihrem Arbeitgeber oder Kunden. Dessen Benutzeradministrator legt ihn in SAP for Me unter der eigenen Kundennummer an. Er gibt Zugriff auf lizenzpflichtige Services wie Support-Fälle, Software-Downloads und Lizenzschlüssel. Wenn Sie gehen, wird er gelöscht.

Die SAP Universal ID hält beide Typen in einer Liste, zusammen mit Ihren Zertifikaten und Ihrer Reputation in der Community.

</details>

<details>
<summary>Kann ich mich noch mit meiner SAP Universal ID anmelden?</summary>

Nein. Seit dem 20. Januar 2026 ist die Universal ID kein Identity Provider mehr. Sie melden sich mit einer S-User- oder P-User-ID an, oder mit der E-Mail-Adresse dieses Users, und mit dem Passwort dieses Users. Die Universal ID funktioniert jetzt wie eine Brieftasche, die Ihre User, Zertifikate und Ihre Reputation in der SAP Community enthält. Zur Verwaltung melden Sie sich weiterhin im SAP Account Manager auf account.sap.com an.

</details>

<details>
<summary>Wie verknüpfe ich nach Juli 2026 einen S-User mit meiner SAP Universal ID?</summary>

Sie fügen die E-Mail-Adresse des S-Users hinzu, statt den User zu verknüpfen. Öffnen Sie im SAP Account Manager die Registerkarte Accounts, klicken Sie auf Add accounts, geben Sie die E-Mail-Adresse ein und bestätigen Sie den Zugangscode, den SAP Ihnen schickt. Jeder S-User und P-User mit dieser E-Mail-Adresse erscheint danach automatisch unter Ihrer Universal ID. User, die Sie vor dem 13. Juli 2026 von Hand verknüpft haben, bleiben verknüpft.

</details>

<details>
<summary>Welche E-Mail-Adresse sollte ich für meine SAP Universal ID verwenden?</summary>

Nehmen Sie eine private E-Mail-Adresse als primäre Adresse und fügen Sie Ihre geschäftlichen Adressen daneben hinzu. Wenn Sie ein Unternehmen verlassen und das Firmenpostfach verlieren, bleibt Ihre Universal ID über die private Adresse erreichbar. SAP empfiehlt dasselbe in der FAQ zur Universal ID.

</details>

<details>
<summary>Was passiert mit meiner SAP Universal ID, wenn ich den Job wechsle?</summary>

Ihre Universal ID bleibt bei Ihnen. Der Administrator Ihres bisherigen Arbeitgebers entzieht oder löscht den S-User. Legt Ihr neuer Arbeitgeber einen S-User mit einer E-Mail-Adresse an, die bereits in Ihrer Universal ID steht, wird er automatisch zugeordnet. Bei einer neuen Adresse fügen Sie diese im SAP Account Manager hinzu.

Ihr P-User und Ihre Universal ID bleiben dabei unverändert.

</details>

<details>
<summary>Wie viele Konten kann ich mit der SAP Universal ID verknüpfen?</summary>

Bis zu 10 E-Mail-Adressen und bis zu 100 S-User oder P-User pro Universal ID. Alle müssen Ihnen gehören. Alles darüber hinaus wertet SAP als Verwaltung von Usern im Namen einer anderen Person, und geteilte Konten führen zur Sperrung.

</details>

<details>
<summary>Ändert die SAP Universal ID, worauf ich in SAP-Systemen zugreifen kann?</summary>

Nein. Jeder S-User behält seine eigenen Berechtigungen. Hat Ihr S-User keine Download-Rechte, bekommt er sie auch nicht dadurch, dass er einer Universal ID zugeordnet wird. Der Benutzeradministrator Ihres Unternehmens vergibt die Berechtigungen in SAP for Me.

</details>

<details>
<summary>Was soll ich tun, wenn ich mich nicht bei SAP anmelden kann?</summary>

Prüfen Sie zuerst, mit welchem User Sie sich anmelden. Seit Januar 2026 hat jeder S-User und P-User sein eigenes Passwort, nutzen Sie also „Passwort vergessen“ für genau diesen User. Teilen sich mehrere User Ihre E-Mail-Adresse, melden Sie sich stattdessen mit der User-ID an.

Haben Sie den Zugriff auf die E-Mail-Adresse des Kontos verloren, wenden Sie sich an das Customer Interaction Center von SAP oder eröffnen Sie einen Support-Fall. SAP prüft Ihre Identität, bevor es den Zugang wiederherstellt.

</details>
