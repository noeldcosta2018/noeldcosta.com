如果您有不止一个 SAP 账户（个人的 P-User，加上雇主或客户提供的 S-User），SAP Universal ID 就是把它们聚在一起的个人账户。它在 2026 年变了两次。从 1 月 20 日起，它不再用于登录：您现在用 S-User 或 P-User 的 ID，或该用户绑定的邮箱，再加上该用户自己的密码登录。从 7 月 13 日起，手动关联取消。您在 SAP Account Manager 中添加邮箱地址，所有邮箱匹配的用户就会自动关联。如果您还没有设置，请用个人邮箱在 account.sap.com 注册，再添加工作邮箱。

刚接触 SAP 时，我花了好几个星期，才弄明白 Universal ID、S-User 和 P-User 是怎么配合的。在有 Universal ID 之前，管理这些账户简直是噩梦：到处是密码表格，一忘记哪组凭据用在哪里，就要不停地收重置邮件。

## S-User、P-User 与 Universal ID 对比

下表列出了每种 ID 归谁所有、用来做什么。

| ID 类型 | 归谁所有 | 用途 | 离职时 |
|---|---|---|---|
| **P-User** | 您本人 | SAP Community、试用、开发者内容、SAP Learning | 没有变化，它属于您 |
| **S-User** | 您的雇主或客户，挂在对方的 SAP 客户编号下 | 支持工单、软件下载、许可证密钥、SAP for Me 中的系统数据 | 管理员将其删除，或到达有效期 |
| **Universal ID** | 您本人 | 把您的 S-User 和 P-User 放进同一个列表，另有学习证书和 SAP Community 声誉 | 您继续保留。添加新雇主的邮箱即可 |

我的 P-User 已经跟了我大约 16 年，换过好几份工作。我在不同公司之间流转时，用过六个不同的 S-User。Universal ID 就是把它们全放进同一个列表的地方。

Universal ID 请用个人邮箱，不要用工作邮箱。SAP 自己的常见问题解答也是这样建议的。如果您离开公司，工作邮箱也用不了，个人邮箱就是您重新进入的途径。

## 2026 年有什么变化

SAP 今年做了两项改动，都会影响您的登录方式和账户关联方式。官方说明见 [SAP 的 Universal ID 页面](https://www.sap.com/account/universal-id.html)。

<explainer-timeline title="SAP Universal ID 在 2026 年的变化" caption="自 7 月起，添加邮箱地址就是账户关联的方式，不再有手动关联按钮。" items="2025 年 8 月 => 为每个用户设置密码|2026 年 1 月 20 日 => Universal ID 不再用于登录|2026 年 7 月 13 日 => 账户按邮箱地址关联" notes="要求拥有多个已关联身份的用户在 2026 年 1 月前完成|使用 S-User 或 P-User 的 ID，或其邮箱登录|手动关联已移除，7 月之前建立的关联继续有效" highlight="3" source="SAP Universal ID 页面，sap.com"></explainer-timeline>

1. **2026 年 1 月 20 日：Universal ID 登录关闭。** Universal ID 不再是身份提供方。您用 S-User 或 P-User 的 ID，或该用户绑定的邮箱，加上该用户的密码登录。认证通过 SAP Cloud Identity Services 完成。拥有多个已关联身份的用户，在 2025 年 8 月至 2026 年 1 月期间被要求为每个身份分别设置密码。如果您跳过了这一步，请对每个用户使用 Forgot password。
2. **2026 年 7 月 13 日：按邮箱地址关联。** 手动关联和取消关联的选项已经取消。凡是邮箱登记在您的 Universal ID 中的 S-User 或 P-User，都会自动关联到它。7 月之前手动关联的账户继续保持关联。

对于同时持有多个客户 S-User 的顾问来说，1 月的这项改动是倒退。过去一个登录就能覆盖全部。现在每个 S-User 又有了各自的密码，切换用户就得先退出再重新登录。请在密码管理器里记一笔：哪个 S-User 属于哪个客户、哪个客户编号。

## 设置 Universal ID 并添加账户

### 第 1 步：创建您的 SAP Universal ID

1. 打开 [account.sap.com](https://account.sap.com/)，点击 **Register**。
2. 输入您的姓名和个人邮箱地址，然后设置密码。
3. 接受使用条款。营销订阅选项可选可不选。
4. 输入收件箱里的验证码。验证码的有效期为 15 分钟。
5. 登录 SAP Account Manager。您新的 P-User 会列在 **Accounts** 选项卡上。

整个过程只需几分钟。请备好您其他 SAP 用户的邮箱地址，注册完成后马上添加。

### 第 2 步：添加其他账户的邮箱地址

1. 在 [account.sap.com](https://account.sap.com/) 登录 SAP Account Manager。
2. 打开 **Accounts** 选项卡，点击 **Add accounts**。
3. 输入您想纳入的 S-User 或 P-User 所使用的邮箱地址。
4. 输入 SAP 发送到该地址的验证码。
5. 检查列表。使用该邮箱的所有用户现在都会出现在您的 Universal ID 之下。
6. 对每个地址重复上述操作，然后在 **Personal Info** 选项卡上设置您的主邮箱。

一个 Universal ID 最多可容纳 10 个邮箱地址和 100 个 S-User 或 P-User。每个用户只能放在一个 Universal ID 之下，而且这些用户必须属于同一个人。关于添加额外邮箱或用户，请参阅 SAP 知识库文章 2882908。

### 日常登录

当您的多个用户共用同一个邮箱地址时，SAP 建议用用户 ID（S 或 P 加数字）登录。如果这些用户还共用同一个密码，用邮箱登录会返回错误，因为匹配到的用户不止一个。

要切换用户，请先退出，再用另一个用户登录。SAP 表示，会话内切换功能以后会推出。在账户选择器中，按登录日期排序，可以把您最近用过的用户排在最上面。

## 获取 S-User 或 P-User

### 开通 S-User

S-User 来自贵公司的用户管理员，而不是 SAP。SAP 只会为新客户创建第一个超级管理员。之后，管理员在 [SAP for Me 的 User Management 应用](https://support.sap.com/content/s4m/help/users/admin.html)中申请 S-User。新用户会收到激活链接，有效期为 10 天。请向管理员申请您的角色所需的权限：

1. **支持工单**：创建并跟进事件
2. **软件下载**：安装包、补丁和附加组件
3. **许可证密钥**：为系统申请密钥
4. **系统数据**：维护安装和系统

S-User 绑定在一个客户编号上，不能转移到另一个客户编号。S-User 还有有效期。临近到期时，您可以在 SAP for Me 中申请延期，申请会进入管理员的待办队列。

如果您找不到 SAP 管理员，先问 IT。在较小的公司，可以问财务。出于许可证的原因，他们几乎都有 S-User 访问权，也会知道管理员是谁。

在 RISE with SAP 和 GROW with SAP 项目中，模式是一样的。客户在自己的客户编号下，为其顾问开通 S-User，合作结束时再删除。这是正常的。那是他们的账户，不是您的。

### 注册 P-User

请用您自己的邮箱在 [account.sap.com](https://account.sap.com/) 注册。这样一步就能得到一个 P-User 和一个 Universal ID。P-User 涵盖 SAP Community、免费试用（例如我的 [SAP BTP Cockpit 指南](/zh-CN/master-the-sap-btp-cockpit-simple-steps/)中的试用）、开发者资源和 SAP Learning。它不提供授权支持或软件下载的访问权，那是 S-User 的用途。

## 常见访问错误及解决办法

2026 年这些改动之后，大多数问题都出在邮箱地址和密码上。

| 问题 | 最可能的原因 | 解决办法 |
|---|---|---|
| 您的 Accounts 选项卡中缺少某个用户 | 该用户的邮箱与您的 Universal ID 中的地址不同 | 在 Accounts 下添加该邮箱，或请管理员更正该 S-User 上的邮箱 |
| 用户已关联到另一个 Universal ID | 它属于您以前创建的旧 Universal ID | 向 SAP 支持提交工单（SAP 的 KBA 使用组件 `XX-SER-UID`），请求释放 |
| 邮箱登录失败 | 多个用户共用该邮箱和密码 | 改用 S-User 或 P-User 的 ID 登录 |
| 2026 年 1 月之后旧密码被拒绝 | 现在每个用户都有各自的密码 | 对该具体用户使用 Forgot password |
| 密码被锁定 | 错误尝试次数过多 | 等待，或重置密码。我自己每年至少碰到一次 |
| S-User 未激活或已过期 | 管理员已将其删除，或已超过有效期 | 请该公司的管理员延期或重新开通。如果它来自上一份工作，那就放手 |
| 已登录但无法创建工单或下载 | 该 S-User 没有相应的权限 | 在 SAP for Me 中申请，由管理员批准 |

如果您完全无法登录，SAP 把 Customer Interaction Center（CIC）列为 Universal ID 问题的联系渠道。恢复账户涉及身份核验，所以如果您因为截止日期需要访问权，请尽早开始。

## 加入和离开客户项目时的检查清单

顾问通常在合作的开头和结尾碰上这些问题。我会按下面的顺序处理。

1. **第一天之前：** 确认您的 Universal ID 有一个个人主邮箱。
2. **第一天：** 请客户的管理员在对方的客户编号下为您创建 S-User，使用您在那里会用到的邮箱。
3. **当天：** 在 SAP Account Manager 中添加该邮箱，并检查新的 S-User 是否出现。
4. **第一周：** 只申请您的角色所需的权限。管理员在 SAP for Me 中批准。
5. **合作期间：** 如果您的多个用户共用一个地址，请用 S-User ID 而不是邮箱登录。
6. **离开之前：** 如果您在该 S-User 下获得了证书，请确保您的个人邮箱已在 Universal ID 中。把证书转到新的 S-User 需要提交支持工单。
7. **离开之后：** 预期该 S-User 会被删除。您的 P-User 和 Universal ID 会保留。

如果客户同时给了您 BTP 访问权，那里的登录失败是另一回事。我的 [BTP Cockpit 故障排查指南](/zh-CN/sap-btp-cockpit-issues/)讲了 401 错误。

## 常见问题

<details>
<summary>SAP 中的 P-User 和 S-User 有什么区别？</summary>

P-User 是个人的。您自己注册，它属于您，会随您换工作。它让您可以访问 SAP Community、免费试用、开发者内容和 SAP Learning。

S-User 属于您的雇主或客户。他们的用户管理员在 SAP for Me 中，在对方的客户编号下创建它。它可以访问支持工单、软件下载和许可证密钥等授权服务。您离开时，他们会将其删除。

SAP Universal ID 把这两种用户放在同一个列表里，同时保存您的证书和社区声誉。

</details>

<details>
<summary>我还能用 SAP Universal ID 登录吗？</summary>

不能。自 2026 年 1 月 20 日起，Universal ID 不再是身份提供方。您用 S-User 或 P-User 的 ID，或该用户绑定的邮箱地址，再加上该用户的密码登录。Universal ID 现在更像一个钱包，里面放着您的用户、证书和 SAP Community 声誉。您仍然在 account.sap.com 登录 SAP Account Manager 来管理它。

</details>

<details>
<summary>2026 年 7 月之后，如何把 S-User 关联到我的 SAP Universal ID？</summary>

您添加的是 S-User 的邮箱地址，而不是去关联用户。在 SAP Account Manager 中，打开 Accounts 选项卡，点击 Add accounts，输入邮箱，并确认 SAP 发给您的验证码。使用该邮箱的所有 S-User 和 P-User 随后会自动出现在您的 Universal ID 之下。2026 年 7 月 13 日之前手动关联的用户继续保持关联。

</details>

<details>
<summary>SAP Universal ID 应该使用哪个邮箱地址？</summary>

主邮箱请用个人邮箱，并把工作邮箱一并添加进去。如果您离开公司、工作邮箱也用不了，个人邮箱能让您的 Universal ID 保持可联系。SAP 在 Universal ID 的常见问题解答中也是这样建议的。

</details>

<details>
<summary>换工作时，我的 SAP Universal ID 会怎样？</summary>

您的 Universal ID 会一直跟着您。原雇主的管理员会撤销或删除该 S-User。如果新雇主创建的 S-User 使用的邮箱已在您的 Universal ID 中，它会自动关联。如果使用的是新邮箱，请在 SAP Account Manager 中添加该地址。

在这个过程中，您的 P-User 和 Universal ID 始终不变。

</details>

<details>
<summary>一个 SAP Universal ID 最多可以关联多少个账户？</summary>

每个 Universal ID 最多 10 个邮箱地址和 100 个 S-User 或 P-User。这些都必须属于您本人。超出这个范围，SAP 就视为代他人管理用户，而共享账户会导致被暂停。

</details>

<details>
<summary>SAP Universal ID 会改变我在 SAP 系统中的访问范围吗？</summary>

不会。每个 S-User 保留各自的权限。如果您的 S-User 没有下载权限，把它加入 Universal ID 也不会增加。权限由贵公司的用户管理员在 SAP for Me 中授予。

</details>

<details>
<summary>如果我无法登录 SAP，应该怎么办？</summary>

首先确认您用的是哪个用户登录。自 2026 年 1 月起，每个 S-User 和 P-User 都有自己的密码，所以请对该具体用户使用 Forgot password。如果多个用户共用您的邮箱，请改用用户 ID 登录。

如果您已经无法访问账户上的邮箱，请联系 SAP 的 Customer Interaction Center，或提交支持工单。SAP 会先核实您的身份，再恢复访问权限。

</details>
