我打造這個計算工具，是要讓 CIO 與 CFO 在面對一線系統整合商之前，先有一個站得住腳的區間。它專為 SAP 設計：S/4HANA Cloud、地端 S/4HANA、BTP，以及 RISE with SAP。不是通用的 ERP。SAP 專案的成本結構，與 NetSuite 或 Dynamics 的導入不同，計算工具也反映了這一點。

它在真正重要的意義上也不偏袒廠商：我不賣導入服務。這些數字來自我追蹤過的 50 多個專案，而不是來自價目表。

## 計算公式

這個估算結合了 SAP 定價特有的固定與變動成本項目。

**專案成本 =（授權或訂閱 × 使用者人數 × 部署係數）+ 夥伴導入服務 + 資料移轉 + 客製化與 ABAP 開發 + 訓練與變革 + BTP 與基礎架構 + 上線後支援 + 應變準備金**

在 RISE 與 S/4HANA Cloud 中，授權部分是訂閱，依完整使用者當量（Full Use Equivalent，FUE）與版本來計算。地端 S/4HANA 則是永久授權，加上約為授權費用 22% 的年度維護費。國家與客製化係數會調整最終區間。結果中會列出各類別的明細，讓您看清楚錢實際花在哪裡。

## SAP 導入的真實成本

多數 SAP 專案在整個導入期間，最後花掉的金額落在 **年營收的 2% 至 6%** 之間。落點取決於規模、產業複雜度、法規負擔，以及您打算偏離標準多遠。

1. **小型企業（員工 200 人以下）**：通常為 15 萬至 50 萬美元。範圍有限，採用 FI、CO、MM 等標準模組，常用 Business One 或 GROW with SAP。
2. **中型企業（員工 200 至 1,000 人）**：50 萬至 200 萬美元。模組範圍更廣、有實際的整合範圍，常見的是 RISE 或 S/4HANA Cloud Public Edition。
3. **大型企業（1,000 人以上）**：200 萬至 1,000 萬美元以上。多法人、跨多國、FI/CO 搭配平行分類帳、法規複雜，常用 S/4HANA Cloud Private Edition 或地端。
4. **跨國集團（10,000 人以上）**：1,000 萬至 5,000 萬美元以上。多區域推行、集團合併，以及大規模的變革。

產業很重要。我協助一家製造業客戶調整授權組合、砍掉用不到的模組，讓授權成本降低 32%。另一位客戶差點簽下他們根本不需要的高階支援方案：一次合約調整，每年就省下 22 萬美元。在任何人碰到配置畫面之前，節省的空間就已經藏在合約裡了。

## 依類別看成本明細

在我主導過的多數 SAP 專案中，支出大致是這樣分配的。

| 類別 | 典型占比 | 涵蓋內容 |
|---|---|---|
| 夥伴導入服務 | 30% 至 45% | 一線系統整合商的顧問、配置、專案管理，以及 SAP Activate 交付 |
| 軟體授權或訂閱 | 15% 至 25% | S/4HANA 版本、BTP 服務、RISE 組合、附加方案（Ariba、SuccessFactors、Concur） |
| 內部團隊工時 | 10% 至 20% | 流程負責人、FI/CO 主管、Basis 管理員、業務領域專家（很少出現在廠商報價中） |
| 資料移轉 | 5% 至 15% | 舊系統資料擷取、清理、SAP Migration Cockpit、驗證 |
| 客製化與 ABAP 開發 | 5% 至 15% | ABAP、CDS views、Fiori 應用程式、BTP 擴充、透過 CPI 的整合 |
| 訓練與變革管理 | 5% 至 10% | 終端使用者訓練、關鍵使用者、溝通、SAP Enable Now 內容 |
| BTP 與基礎架構 | 5% 至 10% | BTP 服務、私有雲的超大規模雲端業者託管、網路、中介軟體 |
| 上線後支援與應變準備金 | 10% 至 15% | Hypercare、AMS、範圍變更、未預見的需求 |

貼近標準 S/4HANA 流程的企業，落在區間的低端。什麼都要客製化的企業，則落在高端。客製化是多數 SAP 專案中，最能由自己掌控的單一變數。

<details>
<summary>它涵蓋 RISE with SAP 與 S/4HANA Cloud 各版本嗎？</summary>

涵蓋。部署模式選單包含 RISE with SAP、S/4HANA Cloud Public Edition（GROW with SAP）、S/4HANA Cloud Private Edition，以及地端 S/4HANA。每一種的授權樣貌都不同：RISE 把基礎架構與基本服務捆綁進訂閱，Public Edition 的客製化限制較嚴格，Private Edition 給予更多自由、成本也更高，地端則是永久授權加上約 22% 的年度維護費。

<details>
<summary>客製化程度如何影響 SAP 成本？</summary>

影響很大。大量客製化的企業，導入費用通常多出 30% 至 50%，而且這筆額外負擔不會在上線時結束。客製的 ABAP 與 Z 程式碼必須維護、每次 S/4HANA 版本更新都要重新測試，還要交接給下一個團隊。計算工具針對低、中、高三種客製化程度套用係數，反映這個規律。

最便宜的客製化決策，通常就是不做。標準 S/4HANA 流程經過數十年的反覆打磨。門檻問題在於：這個偏離是給您競爭優勢，還是為了滿足法規要求。如果答案是「我們一直都是這樣做的」，請再想一想。

</details>

<details>
<summary>SAP 持續的維護與支援呢？</summary>

請規劃每年編列導入總成本的 15% 至 20%，用於持續的維護、應用系統管理服務（AMS）與漸進式增強。計算工具會依您指定的年數推估這筆費用，讓跨年度的全貌從一開始就列在董事會文件上。

對 hypercare（上線後的前 30 至 90 天）編列不足的企業，往往要付出相當於三個月外部顧問人天費用的代價，去修補原本應在測試中就抓出來的問題。合理的 hypercare 投入通常是專案總成本的 3% 至 5%，而且應在簽約前就寫進合約。

</details>

<details>
<summary>RISE with SAP 比自行營運地端 S/4HANA 便宜嗎？</summary>

不一定，尤其是放在五到七年的期間來看，而這正是適合的比較區間。RISE 的前期成本較低、訂閱費用可預期，也不必自己處理超大規模雲端業者的採購，但訂閱費用每年都會累積。地端 S/4HANA 的前期授權費與基礎架構支出較高，但沒有訂閱費，年度維護費約為授權費用的 22%。

對已具備 Basis 能力、且使用年限在七年以上的組織，地端的 TCO 往往較低。對希望由 SAP 負責管理整套系統、並偏好營運費用（Opex）而非資本支出（Capex）的組織，RISE 勝出。計算工具可以讓您兩種都模擬。

</details>
